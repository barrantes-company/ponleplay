# PONLEPLAY

PONLEPLAY es un sistema de widgets Android para controlar contenido multimedia de forma rápida, visual y expresiva, con una identidad derivada de BARRANTES CO.

## Estado

Proyecto inicializado. La primera etapa construirá una aplicación Android local con:

- Jetpack Compose
- AndroidX Media3 / ExoPlayer
- MediaSessionService
- Jetpack Glance
- widgets compacto y modular
- reproducción local de audio y video

SYNC ENGINE queda fuera del MVP inicial y funciona únicamente como referencia técnica.

## Dirección visual

Interfaz OLED oscura, sobria y sensorial, con carátulas expresivas, superficies mate y un acento ámbar cálido derivado del sistema visual de BARRANTES CO.
